# Age Calculator

This is a simple web app that helps you calculate your age by entering your date of birth and the current date.

## 📂 Files

- `index.html` – The main webpage
- `style.css` – The design and layout
- `script.js` – The code that calculates the age

## ✅ How to Use

1. Open the `index.html` file in your browser.
2. Enter your **Date of Birth** and the **Current Date**.
3. Click the **Calculate** button.
4. It will show your age in years.
